This is a recompilation of the Mojon Twins' Super UWOL game (originally a 2016 SG-1000-only release) to the ColecoVision.

This is originally a 48 KiB mapperless ROM on the SG-1000 so I had to rearrange some code and data to make it work with the MegaCart mapper (it's a 64 KiB ROM) .

It uses devkitSMS/SGlib and PSGlib for the audio.

Enjoy!
